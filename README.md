# ResumePilot

ResumePilot 是一款本地优先、用户确认驱动的 Chrome / Edge 求职表单填写助手。它支持公共个人信息、多个求职方向档案、本地简历解析、加密附件库、分层答案库、可选 AI 辅助、安全的逐页填写和投递记录。

> 当前版本：`0.1.0` 开发预览版。通用填写引擎已经可用，具体招聘网站仍需按[兼容矩阵](docs/site-compatibility.md)逐站验证。ResumePilot 不承诺“支持所有网站”，也不会自动点击最终提交。

## 核心能力

- 公共资料与多个求职档案复用，默认提供“雷达岗位”和“Agent 开发岗位”两个方向
- PDF / DOCX 文本在本地提取，解析结果必须人工确认
- 简历、成绩单、照片和证书等附件使用 AES-GCM 加密保存
- 中英文表单字段识别和用户自定义字段映射
- 公共、求职方向、公司三级持久化答案库，以及仅本次填写候选
- 对敏感字段逐项确认，保留网页中已有的手动输入
- “填写并进入下一步”采用按钮白名单；最终提交按钮始终由用户操作
- 可选 OpenAI 兼容接口，用于 JD 分析和候选答案；高敏感数据永不发送
- 本地投递记录和加密/未加密备份
- 简体中文和英文界面基础支持

完整范围和验收标准见[产品需求文档](docs/PRD.md)。

## 本地安装

### 使用构建产物

1. 下载 GitHub Release 中的 Chrome 或 Edge 压缩包并解压。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 选择“加载已解压的扩展程序”，并选中解压目录。
5. 点击 ResumePilot 图标，创建主密码和本地资料库。

主密码无法找回。正式录入资料前，请先测试加密备份与恢复流程。

### 从源码构建

需要 Node.js 22 或更高版本：

```bash
npm install
npm run check
```

Chrome 构建位于 `.output/chrome-mv3`，Edge 构建位于 `.output/edge-mv3`。

开发模式：

```bash
npm run dev
npm run dev:edge
```

生成发布压缩包：

```bash
npm run zip
npm run zip:edge
```

可选的隔离浏览器烟雾测试需要 Chromium 或 Chrome for Testing（正式版 Chrome/Edge 会忽略命令行侧载参数）：

```bash
CHROMIUM_PATH=/path/to/chromium npm run smoke:chromium
```

## 基本使用

1. 在管理页完善公共资料和求职方向档案。
2. 在附件页导入对应简历；检查本地解析候选后再写入档案。
3. 打开招聘申请页面并点击扩展图标。
4. 打开侧边栏、扫描页面，并确认推荐的求职档案。
5. 检查每个候选值，单独确认敏感字段。
6. 选择“填写当前页”或“填写并进入下一步”。
7. 到最终页面后自行复核并提交，再确认是否记录为已投递。

验证码、登录、隐私授权和最终提交必须由用户本人完成。

## 隐私与安全

- 无自建后端、无遥测、无远程代码。
- 结构化资料使用 PBKDF2 派生密钥和 AES-256-GCM 加密。
- 附件分别加密并保存在扩展自己的 IndexedDB 中。
- 解锁密钥只在当前浏览器会话的扩展内存存储中暂存，超时后清除。
- API Key 可选择仅当前会话使用，或随本地资料库加密保存。
- AI 调用前展示发送范围；身份证、详细住址、健康信息和附件不会发送。

本地加密无法防御已经控制设备、已解锁浏览器会话或恶意扩展的攻击。更多信息见[隐私说明](docs/privacy.md)和[安全政策](SECURITY.md)。

## 网站支持

ResumePilot 采用“通用引擎 → 招聘系统适配器 → 网站专用适配器”三层结构。当前注册了主流招聘平台、重点企业和常见 ATS 的识别信息，但只有经过真实页面验证并记录日期后才会标记为“已验证”。

新增或修复网站支持请阅读[贡献指南](CONTRIBUTING.md)和[架构说明](docs/architecture.md)。测试和 Issue 中禁止提交真实简历、API Key、身份证号或未脱敏页面内容。
