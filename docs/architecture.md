# ResumePilot 架构说明

## 总览

ResumePilot 使用 WXT、React、TypeScript 和 Manifest V3。扩展不依赖项目后端。

```text
弹窗 / 管理页 / 侧边栏
          │
          ├── 加密资料库与附件库
          ├── 字段匹配、答案匹配、档案推荐
          └── 后台 Service Worker
                    │ activeTab + scripting
                    ▼
             当前招聘页面代理
```

## 目录

- `entrypoints/`：WXT 扩展入口，包括后台、弹窗、管理页和侧边栏。
- `src/core/`：数据模型、加密、附件、简历解析、AI、字段匹配和消息协议。
- `src/adapters/`：网站与 ATS 路由；后续适配器应放在此处。
- `src/ui/`：共享 UI 和资料库状态管理。
- `tests/`：使用虚构数据的单元测试。
- `fixtures/`：用于手工或自动化回归的虚构招聘页面。

## 数据流

1. 页面代理只扫描字段结构、页面标题和候选 JD 文本。
2. 侧边栏在扩展上下文中解密档案并生成填写计划。
3. 用户确认档案、字段和敏感项后，只把选中的具体值发送到页面代理。
4. 页面代理设置控件值并触发输入事件，不保存用户资料。
5. 下一步按钮由严格白名单判断；包含最终提交语义的按钮不会被点击。

## 加密存储

结构化资料作为一个版本化 JSON 载荷加密后写入 `storage.local`。附件逐个加密后写入 IndexedDB，元数据保存在结构化载荷中。备份可导出相同密文，也可在强警告后导出明文 JSON。

## 适配器原则

通用引擎负责标准控件和语义标签。ATS 适配器负责被多个网站复用的自定义组件，企业适配器只处理无法在更低层解决的差异。适配器不得访问解密密钥，也不得绕过侧边栏确认流程。
