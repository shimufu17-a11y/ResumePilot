# ResumePilot 隐私说明

## 数据保存位置

ResumePilot 不提供云端账号或项目自建后端。档案、答案、站点映射、AI 配置和投递记录加密后保存在浏览器扩展的本地存储中；附件单独加密后保存在扩展的 IndexedDB 中。

卸载扩展通常会同时删除这些本地数据。请在卸载或更换设备前导出加密备份。

## 加密与主密码

主密码通过 PBKDF2-SHA-256（当前参数为 310,000 次迭代和随机盐）派生 AES-256-GCM 密钥。每次加密使用独立随机 IV。主密码和派生密钥不会写入持久化存储；解锁会话密钥暂存在扩展自己的 `storage.session` 中，并在锁定、超时或浏览器会话结束时移除。

主密码无法找回。项目没有后门、托管密钥或云端重置功能。

## 网页访问

插件在用户主动打开侧边栏并执行扫描时，使用 `activeTab` 和 `scripting` 权限读取当前页面的可见表单结构。档案值只会在用户确认执行填写后发送到该页面。

若用户为特定招聘域名授予可选站点权限，权限仅用于对应页面的填写和后续适配。插件不读取浏览历史，不在后台爬取招聘网站。

## AI 数据

AI 功能默认关闭。用户启用后，需要自行配置 OpenAI 兼容接口的 Base URL、模型和 API Key。每次发送 JD、档案方向或问题上下文前，界面会展示数据类型和范围并要求确认。

以下内容禁止进入 AI 请求：

- 身份证号及其他证件号码
- 详细家庭住址和户籍详细信息
- 家庭成员资料
- 健康信息
- 简历、证书、成绩单等附件原文

自定义 AI 服务如何处理数据取决于服务提供方。用户应在授权前阅读其隐私政策。

## 诊断与贡献

项目默认无遥测。诊断导出和 GitHub Issue 必须只包含字段结构、适配器版本和浏览器版本，不得包含字段实际值、附件内容、Cookie、令牌或 API Key。

## 安全边界

本地加密主要降低静态存储和备份意外泄露的风险，不能防御已经控制用户设备、已解锁浏览器会话、恶意浏览器扩展或招聘网站自身的行为。
